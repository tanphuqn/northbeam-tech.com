SearchEye — AI-Powered SEO & Link-Building SaaS Platform

A multi-tenant SaaS platform built for SEO agencies: Algolia-powered backlink marketplace, GPT-4 content generation, dual Stripe + PayPal billing — all running on Laravel 9 and Vue 2.7.

Live at searcheye.io

About the Project

SearchEye is a full-stack SaaS platform designed for digital marketing agencies running SEO campaigns. It centralises backlink sourcing, content ordering, task management, SEO analytics, and client reporting in a single product — with a marketplace of publisher sites, an AI writing engine, and integrated billing.

The platform serves agency staff, their clients, external brokers, and publishers through separate role-gated portals. Every order flows through a structured lifecycle of tasks, approvals, and automated jobs — tracked end-to-end from purchase through delivery.

System Architecture

SearchEye follows a layered architecture: Vue 2.7 SPA front-ends consume a Laravel 9 JSON API. Background processing runs through Laravel Horizon on Redis queues. Algolia handles full-text search, MySQL stores all persistent data, and S3 handles file assets.

Key scale indicators:

  • 172 Eloquent models
  • 457 registered API routes
  • 73 background job classes
  • Laravel Telescope for debugging · Laravel Horizon for queue monitoring

Backlink Marketplace with Algolia

The core commercial feature is a searchable marketplace of publisher websites available for guest-post backlink placements. Each Backlink model implements Laravel Scout's Searchable trait and syncs to Algolia on every save.

// app/Models/Backlink.php
use Laravel\Scout\Searchable;

class Backlink extends Model
{
    use Searchable;

    public function toSearchableArray(): array
    {
        $array = $this->toArray();
        $array = $this->transform($array);
        if ($this->site_type()->exists()) {
            $array['site_type'] = $this->site_type;
            $array['no_backlink_select'] = $this->site_type->no_backlink_select;
        } else {
            $array['site_type'] = null;
            $array['no_backlink_select'] = 1;
        }
        return $array;
    }
}

Agency users filter results by domain rating, organic traffic, niche, price range, and link type. Algolia's built-in faceting returns instant results without hitting MySQL.

AI Content Generation — ChatCells

SearchEye implements a proprietary abstraction called ChatCells — database-driven, composable OpenAI chat pipelines. Each ChatCell subclass defines a buildConversation() method; token placeholders like <{|keyword|}> are substituted at runtime before the API call.

// app/ChatCells/ChatCell.php
public function run(int $current_try = 1): mixed
{
    $result = $this->callAPI();  // builds message, swaps tokens, calls gpt-3.5-turbo or gpt-4
    if (isset($result->choices) && $this->verifyOutput($this->history, $result->choices)) {
        return $this->formatOutput($this->history, $result->choices);
    }
    if ($current_try === static::max_tries) {
        return $this->getFailureOutput($this->history);
    }
    return $this->run($current_try + 1);  // retry up to 3 times
}

System prompts live in the ai_scripts database table — non-engineers can update prompts and switch between gpt-3.5-turbo and gpt-4 without code deployments.

Dual Payment Providers — Stripe + PayPal

SearchEye supports two payment methods on the same invoice. The PaymentProcessorInterface defines a common contract; StripeService implements it via Laravel Cashier. PayPal uses srmklive/paypal and is invoked directly on the Invoice model.

// Stripe: app/Providers/StripeServiceProvider.php
$this->app->bind(
    \App\Contracts\PaymentProcessorInterface::class,
    \App\Services\StripeService::class
);

// PayPal: app/Models/Invoice.php
$paypal_order = $provider->createOrder([
    'intent' => 'CAPTURE',
    'purchase_units' => [[
        'amount' => ['currency_code' => 'USD', 'value' => $amount_to_be_paid],
    ]],
    'application_context' => [
        'shipping_preference' => 'NO_SHIPPING',
        'user_action'         => 'PAY_NOW',
        'return_url'          => $return_url,
    ],
]);

SEO Data Integrations

SearchEye aggregates data from three external SEO data providers to keep publisher metrics up to date:

  • Ahrefs — domain rating, URL rating, referring domains, organic traffic
  • DataForSEO — SERP data, keyword rankings, traffic estimates
  • Diffbot — webpage content extraction and entity recognition

Each provider has a dedicated Service class and corresponding background jobs that run on configurable schedules via Laravel Horizon.
